# 安装指南

[返回首页](../README.md) · [使用指南](USAGE.md) · [常见问题](FAQ.md)

AutoDL Helper 是运行在 AutoDL 网页中的游猴脚本。日常使用只需要浏览器和脚本管理器，不需要部署服务，也不需要安装项目开发环境。

## 1. 准备浏览器和游猴

推荐使用当前版本的 Chrome，并从 [Tampermonkey 官方网站](https://www.tampermonkey.net/)提供的入口安装浏览器扩展。

安装后检查：

1. Tampermonkey 扩展处于启用状态。
2. 浏览器允许它在 `https://www.autodl.com` 上运行。
3. 按当前浏览器要求，开启 Tampermonkey 扩展详情中的“允许用户脚本”。Chrome 138 及更新版本提供这个开关，较早版本可能使用开发者模式；具体以[游猴官方说明](https://www.tampermonkey.net/faq.php#Q209)为准。

脚本需要浏览器提供 Web Locks 标签页互斥锁；如果面板提示浏览器不支持，请更新 Chrome。其他脚本管理器或浏览器未在本项目中承诺兼容。

## 2. 安装脚本

### 方式一：从安装链接打开

1. 点击 **[安装 AutoDL Helper](https://raw.githubusercontent.com/zgx949/autodl-helper/main/autodl-scheduler.user.js)**。
2. 如果游猴弹出安装页，检查名称为“AutoDL Helper · 一键抢机”，来源是 `zgx949/autodl-helper` 仓库的 Raw 文件。
3. 阅读脚本权限，点击安装。
4. 在游猴管理面板中确认脚本已经启用。

安装链接指向 `main` 分支中的单文件构建产物。希望固定使用某个版本时，可从仓库的相应版本标签中选择同名文件。

### 方式二：手动复制安装

如果安装链接显示成普通源码页面，或浏览器没有唤起游猴：

1. 打开 [脚本源码](https://github.com/zgx949/autodl-helper/blob/main/autodl-scheduler.user.js)，点击 Raw，复制文件的**全部内容**，包括顶部 `// ==UserScript==` 元数据。
2. 点击游猴图标，选择“添加新脚本”。
3. 全选编辑器中的默认模板，替换为刚才复制的内容。
4. 按 `Ctrl+S`（Windows / Linux）或 `⌘S`（macOS）保存。
5. 返回游猴管理面板，确认脚本已启用。

不要直接把 `src/` 中的模块复制到游猴中。可安装文件是仓库根目录下的 `autodl-scheduler.user.js`。

### 从早期本地版本迁移

如果曾安装名称为“AutoDL 定时抢机”的早期本地版本，请先停止其任务，在游猴中停用或删除旧脚本，再安装公开版“AutoDL Helper · 一键抢机”。不同名称的脚本可能被管理器视为不同副本，不要同时启用。

迁移后检查新脚本中的默认设置和任务记录，不要假定旧版数据一定会被自动迁移。微信通知的 SPT 需要在新页面重新填写。

## 3. 确认安装成功

1. 登录 [AutoDL](https://www.autodl.com/)。
2. 打开 [个人账户 Pro 实例列表](https://www.autodl.com/console/instance/pro/list)。
3. 刷新页面，等待实例列表加载。
4. 确认实例操作区域出现新增的“抢机”按钮，右下角出现“抢机任务”。

**看到按钮只表示脚本已加载，不会自动开始开机。** 需要点击某个实例的“抢机”才会添加该实例任务。

如果没有按钮，请按[排查顺序](FAQ.md#页面没有出现抢机按钮)检查脚本开关、权限、页面地址和重复安装情况。

## 脚本权限说明

| 能力 | 用途 |
| --- | --- |
| 在 AutoDL 控制台页面运行 | 读取当前页面登录信息和实例列表，嵌入按钮、进度及面板 |
| 游猴本地存储 | 保存默认设置、实例任务、状态和脱敏运行记录 |
| 浏览器通知 | 展示任务受理、结束或异常提示 |
| 打开标签页 | 从面板或通知返回 AutoDL 实例列表 |
| 访问 `wxpusher.zjiecode.com` | 仅用于用户主动配置的微信通知 |

可选微信通知的授权与保存 SPT 是独立步骤。不开启微信通知也能完整使用抢机功能。首次发送时，游猴可能要求确认访问推送域名。

## 更新脚本

公开版提供 `@updateURL` 和 `@downloadURL`，游猴可根据自身设置检查更新；检查周期和是否能访问 GitHub 取决于浏览器、脚本管理器及网络环境，不保证实时更新。

手动更新步骤：

1. 查看 [CHANGELOG](../CHANGELOG.md)，了解行为变化。
2. 先停止正在运行的任务，再在游猴中“检查更新”，或重新打开[安装链接](https://raw.githubusercontent.com/zgx949/autodl-helper/main/autodl-scheduler.user.js)。
3. 在游猴中确认更新；如果是手动安装，打开原脚本编辑器，用新版本全文替换并保存。
4. 刷新 AutoDL 页面。
5. 检查默认设置，重新启动需要运行的任务；如使用微信通知，重新填写 SPT。

请更新已有的公开版脚本，避免同时启用多个副本。重复安装可能让状态和页面入口相互干扰。

## 停用与卸载

- **只停止当前任务**：在实例行或任务面板点击“停止”。
- **暂时停用脚本**：先停止任务，再在游猴中关闭脚本并刷新 AutoDL 页面。
- **卸载脚本**：先停止任务，在游猴管理面板删除脚本，再刷新页面。是否同时删除其存储数据，以游猴的卸载选项为准。

在游猴中切换开关或删除脚本，不应被当作已经送达服务端请求的撤销操作。已发出的请求仍可能由 AutoDL 处理；实例运行状态以控制台为准。
